米多力除濕機 3D 展示台 App（PWA）部署說明
==========================================

這個資料夾就是完整的 App。放到任何一個 https 網址底下，手機和電腦就能開啟並安裝到桌面。
不需要上架 App Store / Google Play，也不需要審核。

一、放到網路上（擇一）
------------------------------------------
A. 放在公司網站底下（建議）
   請網站廠商把整個資料夾原封不動上傳，例如：
   https://www.medole.com.tw/showroom/
   條件：必須是 https；資料夾內的檔案與子資料夾（icons、models）都要一起上傳。

B. 免費託管（約 5 分鐘）
   - Netlify Drop：用電腦瀏覽器開 https://app.netlify.com/drop ，把整個資料夾拖進去，
     就會得到一個 https 網址（可再改成自訂網域）。
   - Cloudflare Pages 或 GitHub Pages 也可以，同樣是上傳整個資料夾。

   注意：直接用電腦雙擊 index.html 開啟（file://）無法安裝，也無法離線，一定要放在 https 網址。

二、安裝到裝置
------------------------------------------
iPhone / iPad（Safari）
   1. 用 Safari 開啟展示台網址
   2. 點「分享」按鈕 → 「加入主畫面」→「新增」
   （App 左上角的「安裝 App」按鈕也會顯示這三個步驟）

Android（Chrome）
   開啟網址後，點左上角「安裝 App」，或 Chrome 選單 →「安裝應用程式」。

Windows / Mac（Chrome 或 Edge）
   開啟網址後，點左上角「安裝 App」，或網址列右側的安裝圖示。
   安裝後會以獨立視窗開啟，也會出現在開始選單 / 應用程式資料夾。

三、離線使用
------------------------------------------
裝置第一次「連網」開啟後，App 會把所有檔案（包含 3D 引擎）存在裝置上，
之後在展場、客戶現場沒有網路也能開啟、旋轉、切換型號與組合。

四、分享給客戶或設計師
------------------------------------------
【只給看一台】
在右側面板「分享此型號」按「複製連結」，連結格式如：
   https://你的網址/#set-e8pg/md-140lb
對方開啟後只會看到這一台，看不到型號選單；
對方仍可以在這台的出回風組合之間切換。

【只給看指定的幾台（例如 30～70 公升）】
1. 點左上角型號按鈕，打開型號選單
2. 按最下方「建立限定型號分享連結」
3. 勾選要開放的型號，或按快速選擇（小型 30–70 L、中型 100–140 L、大型 210–300 L、全選、清除）
4. 按「複製連結」，貼給對方
對方的型號選單只會出現你勾選的型號。

【給看全部型號】
型號選單最下方按「複製全部型號連結」，貼給對方即可。
對方如果之前開過限定連結，打開這條也會解除限制，看到全部型號。

【限制會記住】
對方打開限定連結後，這台裝置會記住限制：
刪掉網址後面那段、重新整理、關掉再開、安裝成 App，都還是只看得到那幾台。
你之後再傳一條新的限定連結給他，會以最新那條為準。

【你自己的手機不小心被限制了】
在網址最後面加上 #reset-all 打開一次，例如：
   https://你的網址/#reset-all
就會恢復顯示全部型號。建議測試限定連結時用「無痕視窗」開啟。

【注意】
這是展示用的限制，不是密碼保護。懂程式的人仍可從公開的 GitHub 原始碼看到所有型號。
如果某些型號真的不能外流，請另外開一個只放那些型號的網站。

五、更新內容
------------------------------------------
把新版資料夾整個覆蓋上傳即可。已安裝的裝置下次連網開啟時會自動更新，
不需要重新安裝。

六、檔案說明
------------------------------------------
index.html            App 主頁面
manifest.webmanifest  App 名稱、圖示、開啟方式
sw.js                 離線快取（Service Worker）
engine.js             3D 展示引擎
families.js           同系列機種的共用建模
models/               13 個型號的 3D 建模資料
data.js               規格表（2026 型錄）
icons/                App 圖示
