# 米多力除濕機 3D 展示台

米多力吊隱式除濕機全系列 13 型的 3D 旋轉展示 App（PWA）。手機、平板、電腦都能開啟並安裝到桌面，第一次連網開啟後可離線使用。

- 開啟網址：本儲存庫的 GitHub Pages 網址（Settings → Pages 可查看）
- 安裝：iPhone / iPad 用 Safari「分享 → 加入主畫面」；Android 與電腦點 App 左上角「安裝 App」
- 分享單一型號：App 右側面板「分享此型號」→「複製連結」，對方只會看到該型號
- 產品類別：標題下方「吊隱式除濕機／全熱交換器」切換；全熱交換器為 DC-PM2.5 過濾系列 MH-D2～D13DCPMTHZ（7 款）
- 濾網抽取：自然回風機型在右側「濾網抽取」按「側拉」，濾網會從側邊抽出約一半並轉到回風側
- 全部型號：型號選單最下方「複製全部型號連結」（也會解除對方之前的限定）
- 限定多款型號：型號選單最下方「建立限定型號分享連結」→ 勾選型號 →「複製連結」，對方只看得到勾選的型號（裝置會記住，用 `#reset-all` 解除）
- 更新：把新版檔案覆蓋上傳到本儲存庫，已安裝的裝置下次連網開啟時自動更新

規格資料來源：米多力 2026 型錄、原廠三視圖與 DXF 圖面。
